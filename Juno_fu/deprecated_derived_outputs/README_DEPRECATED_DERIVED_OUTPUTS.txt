These files are archived and must not be used for Juno science analysis.

They contain a proton-equivalent spectral-peak speed proxy derived from
JADE ion logical counts and/or a processed cache containing that proxy.
No official JADE ion moments cover the 2024-12-10/11 bow-shock events.

Active Juno plots and scripts read only physical fields supplied directly
by the PDS MAG and Waves source files.  Updated: 2026-08-11.
