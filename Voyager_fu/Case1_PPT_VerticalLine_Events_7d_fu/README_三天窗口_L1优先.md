## 数据与优先级

MATLAB通过现有IRFU/dataobj直接读取Z盘官方原始年度CDF。L1使用P1第10氢能道的 `FHDU_SectoredRates` 和 `FHDU_SectoredRateUncertainties`。填充值及超出CDF有效范围的数值保留为NaN；负DeltaT整条舍弃，其余按原Epoch所属UTC日/小时格分组，不做时长加权、跨格分摊、插值或新异常值筛选。

各扇区独立对有限非负率做算术平均，零率参与，缺测不当作零。若该格S1–S7均值全部有限且为正，优先采用该L1整格，并将该格全部L2原记录从绘图输入移入替换审计。即便L2完整也按本次用户要求优先L1；不混用两种产品的单个扇区。若L1不完整，则保留原L2记录及原始Epoch/Flux/Sigma；能否显示PAD仍由七扇区完整性和PA有效性决定。

L1通量沿用已批准旧通路 `J=mean(R)/[0.44*(1.78-0.57)]`，均值误差按独立误差假设为 `sqrt(sum(sigma_i^2))/N` 再乘同一因子。任一参与率样本的误差缺失时，平均误差留空，通量点仍保留。无额外背景扣除，S8只作诊断；不恢复样本数、覆盖率、角跨度、磁场RMS或相对误差门限。极大但未被原CDF规则排除的L1值仍可能主导峰值，本次未新设剔除规则。

该历史换算与官方L2校准的一致性仍未确立。源P1能段元数据0.57–0.89 MeV保留，显示能段按用户约定为0.57–1.78 MeV；不会因显示标签修改L2数值。每行分别记录原始/派生来源及采用的换算。
