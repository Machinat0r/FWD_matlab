## 时间格和优先级

1. 原始 Epoch 落在半开事件窗口内；舍弃 DeltaT<0。其余按 Epoch 所属 UTC 日/小时格分组，不依 DeltaT 分摊、加权或扩展，不对缺值做插值。
2. 若一格中至少一条 L2 记录有完整 S1–S7 正通量，该格所有原 L2 记录原样保留，包括其他不完整行。
3. 其余格计算 L1 各扇区的有限非负计数率算术均值。零率参与平均，缺值不当作零；每个扇区独立使用其有效样本。只有七个扇区的均值全部为正时才补入完整 L1 格，不以 L1 单个扇区修补 L2。
4. L1 完整格替换该格不完整 L2 的显示行；原 L2 完整 payload 留在审计 `ReplacedL2`。无法得到完整 L1 时保留原 L2，缺 PAD 继续为空。
5. L1 代表时间为日 12:00 或小时 :30，表内 `DeltaT_s=NaN`，不把平均格宽伪装为原始累计时长。原始 Epoch/DeltaT 列于 `L1SourceRecords` 和候选审计。

## 通量、误差与投掷角

沿用旧程序采用的换算 `J=mean(R)/[0.44×(1.78−0.57)]`。这里 0.44 为旧通路采用的几何因子，1.21 MeV 为其采用能宽；本次没有证明该处理与官方 L2 校准等价。官方 CDF P1 原能段 0.57–0.89 MeV 保留，显示能段继续按用户要求为 0.57–1.78 MeV。两类来源对绝对通量和峰值排序的影响应谨慎解释；单幅 J/Jmax 归一化会消去共同常数因子。

一个扇区的 N 个参与率样本都有有效误差时，均值误差为 `sqrt(sum(sigma_i^2))/N`，再除以相同几何因子和能宽；任一参与误差缺失时，该平均误差留 NaN，通量点保留。此式沿用旧程序并假定所给误差独立，未传播几何因子、能宽、背景或姿态的系统误差。

不扣除 S8，也未恢复论文使用的未公开逐日背景校正。磁场沿用当前程序的同 UTC 日/小时完整 BR/BT/BN 矢量算术均值。本轮 L1 通路不添加最近磁场替代；该格磁场仍缺测时，PA 仍留空。

L1 格中点调用现有已批准的官方预测 CK、标称 LECP 安装和扇区中心，完整 SC→RTN 变换，粒子方向为望向的负号；无 uN=0 或固定 RT 平面。预测姿态不能等同于遥测重建姿态。平均通量配对格中点预测方向及格内磁场均值，未按逐扇区曝光时间加权、未积分有限视场响应，实际安装偏差校准仍缺少。

PAD 仍要求 S1–S7 全部正通量且 PA 有限；不恢复样本数、覆盖率、角跨度、磁场方向 RMS 或相对误差阈值。
