# MMS1 磁尾分段图：2026-07-20—2026-08-15

全部时间为UTC，日期范围为2026-07-20 00:00至2026-08-16 00:00（包含8月15日全天）。

## 分段和图件

使用MMS1官方MEC epht89d轨道的GSM X<0选取磁尾，共8次经过、162个时段、每段2张PNG。
相邻30秒轨道点之间，用MATLAB interp1线性估计X=0穿越时间；分段起点为每次进入磁尾的时刻，每4小时一段，尾段保留。四小时网格与指定日期范围取交集。因此首段也可能不足4小时。时间清单的小数位属于插值结果，不表示轨道边界具有纳秒精度。

- B_Vi_AE：3个panel，磁场、离子流速、AE。
- B_Vi_AE_Ni_Ei：5个panel，磁场、离子流速、AE、离子密度、离子全向能谱。
- MMS1_tail_windows.csv：全部起止时间、经过编号、时长和中点位置。
- index.html：本地浏览入口，按时间段查看两种图。

矢量统一GSM；图题为时段中点的GSM位置，单位RE（沿用原轨道程序的6372 km）。MEC位置只用于选择时段和图题。各观测量保留原生时间轴，未平滑；真实缺口保留。panel紧凑排列，时间标签水平，无事件标记竖线。能谱范围20—40000 eV。

## 程序及运行顺序

程序保存在 C:\Users\Administrator\Documents\FWD_matlab\MMS_fu。

1. 用Python运行 MMS1_tail_20260720_0815_download.py mec，补齐轨道原始CDF。
2. MATLAB运行 MMS1_tail_20260720_0815_intervals，生成磁尾分段。
3. 用Python运行 MMS1_tail_20260720_0815_download.py science，补齐图中使用的MMS产品。
4. MATLAB运行 Overview_MMS1_tail_20260720_0815，依次生成两种图。

两个MATLAB程序均为%%分区的直接脚本，无新增MATLAB function。读取/坐标变换/绘图调用mms.db_get_ts、mms.get_data、mms.db_get_variable、mms.variable2ts、irf.ts2mat、irf_gse2gsm、irf_resamp、irf_plot、irf_subplot、irf_spectrogram、irf_zoom等已有接口。B、Vi、Ni及能谱的程序段由此前overview直接删改复用；Ni按本次参考图使用红色。

下载脚本调用已有MMS_event_overview_20260923_download.py；导入依赖MMS_event_overview_20260923_events.json，因此程序包中一并保留这两个依赖文件。该JSON仅是旧下载模块导入所需，本批实际时间由本批windows.json决定。

默认跳过已有完整图。若要重画指定时段，在MATLAB中运行：
